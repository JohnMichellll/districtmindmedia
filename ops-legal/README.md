# District Mind Media — Private Legal & Evidence Operations

PRIVATE / INTERNAL / OWNER-ONLY

This directory is not part of the public website. It is an operational evidence system for preserving how District Mind Media operates.

Purpose:
- preserve dated operational records and source provenance
- document editorial workflows, AI boundaries, approvals, corrections and incidents
- maintain a defensible record of what was researched, generated, reviewed, published, corrected and removed
- keep evidence separate from public-facing site content

Important:
- This is an evidence/operations system, not legal advice.
- It does not create attorney-client privilege by itself.
- Do not store passwords, API keys, payment card data, SSNs, medical data or unnecessary personal information here.
- Legal holds, subpoenas, preservation requests and litigation should be handled with qualified counsel.
- Public articles should link to sources and follow the site's editorial policy; this private system preserves the underlying operational record.

Core records:
- evidence-log.json — append-only-style index of evidence events
- editorial-decisions.json — material editorial decisions and approvals
- corrections.json — corrections/retractions and rationale
- incidents.json — operational/security/site incidents
- source-registry.json — source provenance and access notes
- ai-activity.json — AI-assisted research/QA activity
- retention-policy.md — internal retention and preservation rules

Never publish this directory or expose it through Cloudflare Pages.
